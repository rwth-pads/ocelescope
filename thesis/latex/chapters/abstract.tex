\chapter*{Abstract}

Object-Centric Process Mining (OCPM) analyzes processes involving multiple interacting objects.
It overcomes the limitations of traditional methods that rely on a single-case perspective.
As the field grows, a variety of research tools have been proposed in scientific publications to support object-centric process mining.
However, these tools are typically developed as standalone prototypes, vary widely in design, are difficult to maintain, and often duplicate similar functionality.

This thesis addresses the need for a unified and extensible approach to tool support in this domain.
A systematic literature review identifies existing object-centric process mining tools introduced in scientific publications and analyzes their technologies, functionalities, and limitations.
Based on these findings, the thesis introduces Ocelescope, a web-based framework that provides core functionality and supports extensibility through plugins and modules.
Plugins enable the implementation of OCPM functions with automatically generated graphical input interfaces.
Modules allow developers to create reusable user interface and logic components for specialized applications.

The framework was fully implemented in this thesis and made available as open-source software.
It was evaluated through two user studies focused on tool usage and plugin development, as well as through proof-of-concept plugins.
The results show that users can effectively use the tool and that developers can implement plugins with little effort.
The evaluation indicates that Ocelescope can simplify the development of object-centric process mining functionality and improve the usability of available tools.
